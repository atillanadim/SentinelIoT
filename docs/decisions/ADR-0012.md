# ADR-0012 — Stack da CLI e padrão de saída

**Data:** 2026-11-08
**Status:** aceito

## Contexto

O MVP precisa de uma CLI simples, utilizável por administrador não especialista,
sem introduzir dependências desnecessárias. O modo de saída deve ser legível e
seguro.

## Alternativas

1. `argparse` da biblioteca padrão, saída em texto simples.
2. Typer/Click.
3. Rich com tabelas e cores.
4. Interface web.

## Decisão

- `argparse` com subcomandos.
- Saída em texto simples por padrão.
- Sem Rich, ANSI obrigatório ou tabelas complexas.
- Opção de saída JSON para automação.
- Mensagens claras e códigos de saída consistentes.
- Confirmação explícita para operações de risco.

## Justificativa

Reduz dependências, funciona em terminais simples e atende ao MVP. A CLI é local
e não deve abrir listener de rede.

## Consequências

- Menos recursos visuais.
- Mais código manual para parsing e ajuda.
- Interface web fica para evolução posterior.
- A acessibilidade depende de mensagens claras.

## Riscos

- Saídas longas podem ficar difíceis de ler.
- Falta de cores pode reduzir destaque de erro.
- A opção JSON precisa de schema estável.
