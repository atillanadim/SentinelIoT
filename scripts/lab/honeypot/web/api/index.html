SentinelCam API v1

Endpoints

GET  /api/status
GET  /api/v1/device
POST /api/v1/login        {"username":"...","password":"..."}
POST /api/v1/config       {"rtsp_port":554}

Autenticação por token do dispositivo. Requisições sem token retornam 401.

curl -s http://10.10.10.10/api/status
curl -s -X POST http://10.10.10.10/cgi-bin/sentinel_api.py \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"teste"}'
